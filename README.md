# Машинный Дух Ошибок

> *In the name of the Omnissiah, who is the Machine-God, and through the sacred
> rites of the Binary Cant, we invoke the Litany of Sorting. Let the errors of
> the Pages-schemas be gathered, classified and bound into Reports, that the
> Tech-Priests may know where the Machine-Spirit suffers.*

Скрипт собирает все ошибки модуля Pages-схем с эндпоинта менеджера,
группирует однородные из них в **кластеры** и выносит **отчёт** рядом с собой.
Зависимостей нет, нужен только Python 3.

---

## I. Обряд подготовки (однократно)

1. **Призовите сервитора-пользователя.** В карточке служебного пользователя
   менеджера выдайте API-токен кнопкой «сгенерировать». Токен показывается
   единожды, как священный ключ. Пользователь должен обладать правом
   «Ошибки» модуля Pages-схем и иметь включённый API-доступ.
2. **Освятите конфигурацию.** Скопируйте `.env.example` в `.env` и вставьте
   адрес Машинного Духа менеджера и токен:

   ```bash
   cp .env.example .env
   $EDITOR .env
   ```

   `.env` не покидает вашу машину: он внесён в `.gitignore`, и никакой
   Адепт не должен видеть его в открытом репозитории.

## II. Литания запуска

```bash
python3 cluster_errors.py              # вечный цикл: обход каждые 30 минут
python3 cluster_errors.py --once       # один обход и возврат к Машинному Духу
python3 cluster_errors.py --file x.json  # офлайн: читать дар Духа из файла
```

Для расписания по канону cron, вместо вечного цикла:

```
*/30 * * * * cd /путь/к/pages-errors-cluster && python3 cluster_errors.py --once >> reports/cron.log 2>&1
```

## III. Дары, которые вы получите

| Файл | Что внутри |
|---|---|
| `reports/latest.md` | Последний отчёт, читаемый человеком |
| `reports/latest.json` | Тот же отчёт для машин и других программ |
| `reports/report-ГГГГ-ММ-ДД_ЧЧ-ММ.*` | Архивные отчёты, хранятся 400 последних |
| `state.json` | Память Духа: все кластеры, которые уже встречались |

В отчёте: общее число записей и открытых, топ кластеров (открытые, повторы,
за 24 часа, число доменов), **новые** кластеры с прошлого обхода и подробности
по каждому с примерами сообщений, схемами и доменами.

## IV. Учение о кластеризации

Каждое сообщение приводится к **шаблону**: URL, адреса почты, шестнадцатеричные
идентификаторы, IP, домены, строки в кавычках и числа заменяются метками.
Ошибки с одинаковым шаблоном, источником и уровнем составляют один кластер.

Это группировка по тексту, без машинного обучения. Ошибки, описанные разными
словами, в один кластер не попадут: Духу нужно, чтобы ему говорили одно и то же
одинаково.

## V. Предостережения

- Эндпоинт отдаёт все ошибки модуля, включая детали контекста. Не выкладывайте
  отчёты в открытый доступ без проверки.
- Токен даёт право читать ошибки. Отзовите его в карточке пользователя, если он
  попал не в те руки.

*Omnissiah, ascribe fidelity to the logs.*
